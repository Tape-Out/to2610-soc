# to2610-soc 流片说明

流片说明报告（docx）的功能描述、寄存器含义、板级连接、测试说明与局限从这里取，只写在这一处。

## 功能描述

外设齐全的 Linux 系统芯片，面向 ECOS 2610 班车。它是 `to2610-kvc` 那一颗（KianV 的 RV32IMA、Sv32 SoC）在地址图上开了一段窗，窗后面是从组织的 IP 库里用息壤装配出来的十五个外设。原有的串口、Flash、SDRAM、SD 卡口、SPI 网卡口与 Linux 的启动路径一样不动，同一份镜像照样起得来；新加的外设裸机与 Linux 下都能用。

KianV 的 SoC 是上游的，子模块不动；源码取黑盒仓拼好的那一份，带着它修机器态软件中断的一行补丁。本仓自己写的有四样：`patch/soc.patch` 在上游的 `soc.v` 上开地址窗并把片上总线与中断引出来（三十来行）；`hwsrc/kv_apb.v` 把 KianV 的总线转成 APB4；`hwsrc/soc_core.v` 把核、桥与外设块接在一起；`hwsrc/soc_frame.v` 是 Frame 形态的引脚复用。外设块 `soc-io` 是一份息壤的装配清单，没有手写的连线。

### 功能一览

| 项 | 支持 | 说明 |
|:--:|:--:|:--:|
| 处理器、存储、原有外设 | 同 `to2610-kvc` | RV32IMA、Sv32，片外 SDRAM 32 MiB 与 SPI Flash，串口 0（控制台）、SD 卡口、SPI 网卡口、1 位 GPIO |
| 串口 1 | 带 RTS、CTS 流控，收发各 8 字节的队列 | 留给片外的模块：蜂窝模块、WiFi 与蓝牙模块的 AT 口 |
| GPIO 1 | 16 位，逐位方向，上升沿中断 | Frame 形态引出低 12 位 |
| 计时器 | 两路比较、两路输入捕获，16 位预分频 | |
| 看门狗 | 32 位，带窗口 | 到点可出复位脉冲到引脚 |
| 实时时钟 | 64 位计数，一路闹钟 | 掉电不保持：片上没有备份域 |
| I2C | 主机，7 位与 10 位地址 | 开漏，板上要上拉 |
| SPI 2 | 主机，单线全双工，两个片选 | 接屏、传感器，或去管别的芯片的 SPI 管理口 |
| 单总线 | 主机，标准速度，带 CRC-8 | 开漏，板上 4.7 kΩ 上拉 |
| PWM | 4 路，16 位周期与占空 | MPW 形态另出 4 路互补 |
| I2S | 主机，16、24、32 位，收发各一路 | 功放与数字麦克风 |
| CAN | 经典 CAN 2.0B，标准帧与扩展帧，一组验收滤波 | 板上要收发器 |
| PS/2 | 主机，收发 | 5 V 接口，板上要电平转换 |
| 以太网 | `emac`：100 Mbps 的 RMII MAC，收发各一帧缓冲，每帧到 528 字节 | PHY 在片外，出 8P8C，能直接插 `to2610-switch`；主机的 MTU 设 498，与组网实验里过路由器的设法相同 |
| 随机数 | 片外噪声源进来，带健康检测与调理 | 只有 MPW 形态与 Frame 的第 3 组引出噪声脚 |
| CRC | 宽度、多项式、初值、反转都可配，到 32 位 | |
| SerDes | 一条全数字的串行通道（`serdes` 仓）：8b/10b 编解码、四倍过采样的接收端从数据里跟时钟、逗号定界、PRBS15 发生与核对、片内自环 | 单端两根脚，线速率是线路时钟的四分之一，Frame 形态下是 12.5 Mbit/s；两颗芯片各用各的晶振也能对接 |

### 外设怎么用

裸机下直接读写下一节那张表里的地址；每个外设的寄存器在它自己仓的 `regmap.yaml` 里，`ran gen <名字>` 出 C 头文件，本仓的整片测试 `htest/xio/xio.c` 就是照这些头文件写的，可以当例程看。

Frame 形态下外设的脚要先选出来：往 `0x4003_0004` 写每根复用焊盘两位的选择（见「板级连接」），再去用对应的外设。复位后 12 根都是 GPIO。

### 启动与软件

启动流程、引导程序、镜像与烧录办法同 `to2610-kvc`：复位后从 Flash 的 `0x2010_0000` 就地执行引导程序，它把紧跟在后面、1 MiB 又 64 KiB 处的载荷搬进 SDRAM 再跳过去。串口 0 是默认的调试输出与控制台，115200。按住复位时全部引脚高阻，烧录器夹上 Flash 就能在板写。

这一版 Linux 下还没有新外设的驱动与设备树结点，用 `devmem` 直接读写寄存器（镜像里有）。

## 寄存器

KianV 原有的地址见 `to2610-kvc` 的流片说明。窗在 `0x4000_0000`，核对这一段的读写原样变成 APB4 的传输；窗里没有东西的地方读回 0、写了不管，不陷入。

| 地址 | 外设 | 中断（PLIC 的号） |
|:--:|:--:|:--:|
| `0x4000_0000` | 串口 1（`uart`） | 11 |
| `0x4000_1000` | GPIO 1（`gpio`） | 12 |
| `0x4000_2000` | 计时器（`timer`） | 13 |
| `0x4000_3000` | 看门狗（`wdt`） | 14 |
| `0x4000_4000` | 实时时钟（`rtc`） | 15 |
| `0x4000_5000` | I2C（`i2c`） | 16 |
| `0x4000_6000` | SPI 2（`spi`） | 17 |
| `0x4000_7000` | 单总线（`onew`） | 18 |
| `0x4000_8000` | I2S（`i2s`） | 19 |
| `0x4000_9000` | CAN（`can`） | 20 |
| `0x4000_A000` | PS/2（`ps2`） | 21 |
| `0x4000_B000` | 随机数（`rng`） | 22 |
| `0x4000_C000` | 以太网（`emac`），帧缓冲区在 `0x4000_D000` | 23 |
| `0x4000_E000` | PWM（`pwm`） | 无 |
| `0x4000_F000` | CRC（`crc`） | 无 |
| `0x4001_0000` | SerDes（`serdes_apb`），寄存器见 `serdes` 仓的自述 | 27 |
| `0x4003_0000` | 标识，只读，`0x534F4331` | |
| `0x4003_0004` | 引脚复用 `PADSEL`：第 2k+1:2k 位选第 k 根复用焊盘的功能，复位全 0 | |

PLIC 的 10 号仍是串口 0。

## 板级连接

payload 的前 54 位与 `to2610-kvc` 逐位相同（串口 0、Flash、SDRAM、SD 卡口、SPI 网卡口、1 位 GPIO），两颗芯片用同一块底板，接法见 `to2610-kvc` 的流片说明。余下 12 位（payload 第 54 至 65 位，下面叫 x0 至 x11）每位四选一：

| 焊盘 | payload 位 | 0（复位） | 1 | 2 | 3 |
|:--:|:--:|:--:|:--:|:--:|:--:|
| x0 | 54 | GPIO 0 | 串口 1 TXD | RMII TXD0 | SPI 2 SCK |
| x1 | 55 | GPIO 1 | 串口 1 RXD | RMII TXD1 | SPI 2 CS0_N |
| x2 | 56 | GPIO 2 | 串口 1 RTS_N | RMII TX_EN | SPI 2 MOSI |
| x3 | 57 | GPIO 3 | 串口 1 CTS_N | RMII RXD0 | SPI 2 MISO |
| x4 | 58 | GPIO 4 | I2C SCL | RMII RXD1 | SerDes TX |
| x5 | 59 | GPIO 5 | I2C SDA | RMII CRS_DV | SerDes RX |
| x6 | 60 | GPIO 6 | 单总线 | RMII RX_ER | SPI 2 CS1_N |
| x7 | 61 | GPIO 7 | CAN TX | PWM 0 | I2S SCK |
| x8 | 62 | GPIO 8 | CAN RX | PWM 1 | I2S WS |
| x9 | 63 | GPIO 9 | PS/2 时钟 | PWM 2 | I2S SD 出 |
| x10 | 64 | GPIO 10 | PS/2 数据 | PWM 3 | I2S SD 入 |
| x11 | 65 | GPIO 11 | 计时器捕获 0 | 看门狗复位出 | 随机源入 |

payload 第 n 位是 MPC-Frame 的 `user_io[n + 7]`；逐位的完整位表在报告的「payload 位表」里。

- 时钟 50 MHz。用以太网时必须与 RMII PHY 的 `REF_CLK` 同源：一颗晶振经扇出缓冲同时给芯片与 PHY，PHY 设成参考时钟输入。
- 以太网：第 2 组的 x0 至 x6 接一颗 RMII PHY（LAN8720A、RTL8201F 一类），配带网络变压器的 8P8C 插座。复用是逐根选的：x0 至 x6 选第 2 组的同时，x7、x8 留作 GPIO 去拨 PHY 的 MDC、MDIO（MDIO 要上拉）；不接也行，PHY 靠配置脚定成自协商，对端要支持 100 Mbps 全双工。TX_EN 在板上留一颗 10 kΩ 下拉。
- 开漏的脚（I2C 两根、单总线、PS/2 两根）各要一颗上拉：I2C 与单总线 4.7 kΩ 到 3.3 V；PS/2 是 5 V 接口，要过电平转换。
- CAN 的 TX、RX 接一颗 3.3 V 的收发器（SN65HVD230 一类）。
- 串口 1 接片外模块的主串口，四根线交叉接（TXD 对 RXD，RTS_N 对 CTS_N）。
- SerDes：两颗芯片对接时 TX 对 RX 交叉接，共地，线尽量短（单端 3.3 V 电平，没有差分驱动与均衡）；自己测自己就把 x4 与 x5 短接。
- 没选到焊盘上的外设，输入拿到的是空闲电平，不会误动作。
- 复位：按住复位时全部 payload 脚高阻。

## 测试说明

测试台 `tb.cpp` 来自黑盒仓，跑在 Verilator 上，带 SDRAM、Flash、串口的引脚级模型。被测的是 `ran asic` 出的那份交付文件。12 根复用焊盘在测试台上按选中的功能组接回环或最小的片外模型（`htest/shim.py`）。

| 用例 | 测什么 |
|:--:|:--:|
| hello、periph、isa、boot | `to2610-kvc` 的四段原样再跑（裸机冒烟、原有外设、riscv-tests 七十九个、引导程序）：开了地址窗、接了外设之后，原有的通路与核的行为不许变 |
| rtos、image | `to2610-kvc` 的 FreeRTOS 冒烟原样在这一颗上跑；它的 Linux 镜像先在 QEMU 上起到 shell |
| linux | 同一份镜像在这一颗上从 Flash 引导到 shell、跑那组命令。这一颗的仿真每秒不到三十万拍，起一遍要五六个小时，流水线上不跑，带 `SOC_LINUX=1` 在本机跑 |
| xio：地址 | 窗里的空地址读回 0；六个外设的复位值各不相同、逐个读对；十五个实例各写一个不同的数，全部写完再读回，两个实例译到同一页或哪一页没人应就对不上 |
| xio：GPIO | 对接的两组脚互相读到、松手后是上拉；上升沿中断经 PLIC 的 12 号进来 |
| xio：串口 1 | 500 千波特发四个字节，从回环收回来，流控开着；发送水位中断经 11 号进来 |
| xio：单总线 | 发复位，板上的器件应存在脉冲 |
| xio：PS/2 | 板上的设备送来扫描码 0x1C |
| xio：以太网 | 发一帧广播，经 RMII 的回环从接收缓冲区读回，内容相同、长度 64 |
| xio：SPI 2 | 板上的回声从设备每个字节回上一个字节的反码，片选在四个字节之间按着不放 |
| xio：I2S | SD 出接回入，左右声道各收回发出去的数 |
| xio：SerDes | 片内自环发四个字节、原样收回，收到字节的中断经 27 号进来；再经焊盘 x4 出、x5 回跑 PRBS，零误码；线上翻一位，记到错 |
| xio：计时器 | 数到比较值，中断经 13 号进来 |
| xio：CRC | CRC-8/MAXIM-DOW 算 `123456789` 得 0xA1 |

外设各自的功能在各自的仓里测（配置矩阵、行为测试、变异）；整片这一层验的是只有这一层才会错的三样：地址、引脚、中断号。

## 局限

- 同 `to2610-kvc` 的各条：缓存旁路、主频固定 50 MHz、没有 JTAG、核与规范不符的几处。
- I2C、CAN、PWM、看门狗、实时时钟、随机数这六个在整片上只核到寄存器读写，引脚没有接片外模型测过。
- Frame 形态一次只能引出 12 根外设脚，GPIO 1 的高 4 位、PWM 的互补输出、计时器的第二路捕获引不出来。
- 以太网没有硬件的 MDIO，要用就拿两根 GPIO 由软件拨；`emac` 收发各只有一帧缓冲、每帧到 528 字节（缓冲区是触发器搭的，放大就是面积），软件来不及取时后到的帧丢掉。
- SPI 2 是单线全双工。IP 的多线档每一帧只发或只收、不能逐帧换协议，接不了要先发单线命令的 QSPI Flash，所以没有用。
- Linux 下新外设还没有驱动，只能经 `/dev/mem` 读写。
- USB 没有做。
